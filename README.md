# Conversational Chatbot | Joonbot 🤖

## Overview
A customizable conversational chatbot created using Joonbot, a no-code chatbot builder. The chatbot interacts with users through structured questions, selectable options, and conversational flows to collect relevant information.

## Objective
To explore chatbot creation and understand how conversational automation can simplify information collection, improve user interaction, and support different business needs.

## Key Features
- Interactive question-and-answer flow
- Multiple-choice response options
- Structured information collection
- Customizable conversation paths
- Branching based on user responses

## Potential Applications
The chatbot concept can be adapted for different purposes, such as:
- Recruitment and job applications
- Customer support and FAQs
- Lead generation
- Student enquiries
- Employee onboarding
- Surveys and feedback collection

## Tool Used
- Joonbot – No-code chatbot builder

## Learning Outcomes
- Understanding chatbot workflow design
- Creating structured conversational flows
- Designing user-friendly questions and response options
- Exploring automation in different business functions
